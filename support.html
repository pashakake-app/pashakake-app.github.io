よくある質問

Q. 「パシャ家計簿」ってどんなアプリ?

決済通知やレシートのスクリーンショットを共有するだけで、AIが自動で支出を記録する家計簿アプリです。手入力はほぼ不要で、面倒な家計管理を最小限の操作で実現します。

Q. 記録データはどこに保存される?

ユーザーの端末内にのみ保存されます。サーバーには送信されません。詳しくはプライバシーポリシーをご確認ください。

Q. サブスクリプションの解約方法は?

iPhone の「設定」アプリ > Apple ID > サブスクリプション から、いつでも解約できます。

Q. Claude API や ChatGPT API を使うとどうなる?

オンデバイスAI(デフォルト)より高精度な解析が可能になります。設定は任意で、使わなくてもアプリは利用できます。APIキーはユーザー自身で Anthropic / OpenAI のサイトから取得する必要があり、利用料金はそれぞれのサービスに直接発生します。

Q. 撮影した画像はどこに保存される?

画像自体は保存されません。OCR で抽出したテキストのみが記録データとして保存されます。

不具合報告

不具合を見つけた場合、以下の情報を添えてご連絡いただけると、解決が早くなります。

  • iOS のバージョン
  • アプリのバージョン(設定画面の下部で確認できます)
  • 発生した状況(どの画面で、何をしたか)
  • エラーメッセージがあればその内容
